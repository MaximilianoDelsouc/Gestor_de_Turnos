# Gestor de Turnos 

**Aplicación de escritorio** CRUD de Java para gestionar turnos en un consultorio.

## Descripción

El objetivo de este proyecto es ser un gestor de turnos personal, sencillo y local para una persona que trabaje en un consultorio médico o ambientes similares. Funciona como un CRUD simple que consta de tres entidades: Pacientes, Tipos de consultas y Turnos, permitiendo asignar turnos a pacientes previamente registrados y especificar el tipo de consulta que se realizarán. Esta aplicación busca principalmente evitar el solapamiento en los horarios de los turnos, reprogramar y cancelar turnos fácilmente, llevar un registro del historial de turnos de cada paciente, y mostrar los turnos y pacientes que deberá atender el usuario durante el día.
